# Marketing site

Public homepage. Single page, scroll-snapping sections, warm paper canvas with the flow-line motif behind the hero. Built as a recreation of what InflowMind's marketing page *would* look like — the backend codebase has none.

## Files

- `index.html` — fully scrollable marketing page with sticky nav
- `Header.jsx` — sticky top nav (becomes blurred on scroll)
- `Hero.jsx` — full-bleed hero with flow-line illustration
- `HowItWorks.jsx` — three-up "Upload · Ingest · Ask" with mini ingestion-pipeline animation
- `Pricing.jsx` — three-tier pricing table
- `Footer.jsx`

## Run

Open `index.html` in a browser. All assets resolve relative.
